# Rithick Raman — Portfolio

Personal portfolio built with React, TypeScript, and Vite. Project cards describe selected work without exposing private source repositories or demo links.

## Local development

```sh
npm ci
npm run dev
```

## Checks

```sh
npm run typecheck
npm run lint
npm run build
```

## GitHub Pages

The `Deploy to GitHub Pages` workflow builds and publishes the site on pushes to `main`. The production build uses the `/rithick-portfolio/` base path for the repository Pages URL; local builds keep the root path.
